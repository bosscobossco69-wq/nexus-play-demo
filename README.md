# NEXUS PLAY Demo

深蓝科技风线上娱乐演示网站原型。

## 运行方式
1. 解压 `nexus-play-demo.zip`
2. 在浏览器打开 `index.html`，即可查看原型
3. 可用 VS Code 打开文件继续开发
4. 部署到 Vercel 时，可将此文件夹作为静态项目部署

## 已实现的前端原型
- 总览首页与模拟余额
- 游戏大厅（3 款轻量互动小游戏）
- 本地演示登录与会员资料
- 模拟钱包与交易记录
- CSV 导出
- 管理后台演示积分调整
- 手机端响应式布局

## 重要限制
此版本只使用浏览器 localStorage 保存演示数据。登录不是真实身份验证，管理后台没有服务端权限保护，不能用于生产环境，也不接入真实支付、充值、提现或真钱博彩。下一阶段应接入 Supabase Auth 和数据库，并通过服务端角色策略保护管理员功能。
